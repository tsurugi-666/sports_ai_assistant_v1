# 🏋️ ИИ-Помощник по подбору спортивных упражнений

Интеллектуальная система (Экспертная система + Нейросеть) для подбора персональных спортивных тренировок и упражнений.

## 📌 Реализованные модули знания и ИИ

1. **Семантическая сеть**: Моделирование взаимосвязей между упражнениями, инвентарем и группами мышц.
2. **Логическая модель**: Вывод на основе булевой логики ($AND, OR, NOT$) с механизмом объяснения решений.
3. **Продукционная система**: Прямой вывод ($Forward\\ Chaining$) на базе продукционных правил ("ЕСЛИ ... ТО ...").
4. **Фреймовая модель**: Представление знаний через фреймы с механизмом наследования свойств (слоты $is\_a$).
5. **Машинное обучение и Нейронные сети**: Классификатор (RandomForest) и простая нейросеть (MLP) для прогнозирования категории тренировки.
6. **Экспертная система**: Объединение всех модулей знаний в единого ИИ-помощника.
